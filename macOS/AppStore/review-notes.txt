VibeZip is a free, native archive manager for macOS 26 or later. No account, sign-in, subscription or in-app purchase is required.

First launch and file access
Drop a single archive onto the empty window to open it, or click Add Folder… in the sidebar to browse a folder. VibeZip uses App Sandbox and works with files and folders authorized by the user. Opening a dropped archive does not require access to its parent folder. Editing an archive can request access to its containing folder so the app can create and verify a staged update before replacing the original. This is not a request for Full Disk Access.

Suggested review flow
1. Save the attached review-sample.zip and drop it onto the empty VibeZip window. It should open without a parent-folder access request. It contains demonstration text files and Samples/Nested.zip; no passwords or accounts are needed.
2. Navigate to Samples, open Nested.zip inside the archive, then select Readme.txt and click Preview.
3. Extract review-sample.zip into a local folder and authorize that folder in VibeZip. Select local text files and use Add to create a ZIP or 7z archive. The compression dialog also provides optional password encryption.
4. Open the newly created ZIP. Drag another local file from Finder into the file list and choose Add to Archive, then use Test to check the archive. Every single-item drop into a writable archive offers Open, Add to Archive and Cancel, regardless of file type. Existing names require update confirmation. Changes can also rename or delete entries in supported writable formats.
5. Enable 2 Panels to browse an archive and a filesystem folder side by side. Settings manages saved folder access and temporary storage, including Show Temporary Folder and Clean Temporary Files.
6. Choose File > New Window to open another browser window. Windows share archive sessions and folder access. Closing all windows leaves the app running; click the Dock icon to open a window again, or choose Quit VibeZip to exit.

Privacy and limitations
Processing stays on the Mac. The app has no analytics or advertising, and its sandbox disables incoming and outgoing network connections. Archive passwords stay in memory. Preview and nested archive operations can create temporary copies, including decrypted data. Cleanup preserves files that are still in use; optional recovery copies are off by default and are not permanent backups.

RAR and multivolume archives are read only. Built-in previews show text, images, hexadecimal data and the first page of a PDF, subject to size limits. Archive contents are not executed or opened in external viewers. The About window's GitHub button opens the project website in the system browser; explicit reveal actions use Finder.

The app includes its corresponding source and open-source license notices. It has English, Simplified Chinese, Japanese and Korean interfaces. This release is not being distributed in France.
