# VibeZip for macOS

A native archive manager powered by the in-process 7-Zip engine.

- Sidebar, editable path, Icons/List/Details views and a live Info inspector.
- Browse nested archives, preview files locally, compress, extract and test.
- App Sandbox with user-selected folder access and persistent bookmarks.
- Universal application for Apple Silicon and Intel; requires macOS 26 or later.

Open the DMG and drag VibeZip to Applications. Choose a folder on first launch.
Folder permissions can be managed in Settings → Folder Access.

Public DMGs are Developer ID signed and notarized. Archives are processed on
your Mac. This is an independent project, not an official 7-Zip release.
