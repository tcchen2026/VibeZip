VibeZip 개인정보 보호

VibeZip은 사용자의 Mac에서 파일을 처리합니다. 파일, 파일 이름, 암호, 탐색 기록 또는 사용 데이터를 수집하거나 전송하지 않습니다. 분석, 광고, 계정 시스템 또는 네트워크 접근 기능이 없습니다.

폴더 접근 권한
VibeZip이 탐색하고 관리할 수 있는 폴더는 사용자가 선택합니다. VibeZip은 macOS 보안 범위 책갈피와 폴더 경로를 로컬에 저장하여 접근 권한과 마지막으로 방문한 디렉토리를 기억합니다. 설정 > 폴더 접근 권한에서 저장된 접근 권한을 추가, 재승인 또는 제거할 수 있습니다. 접근 권한을 제거하면 저장된 책갈피가 제거되며 파일은 삭제되지 않습니다. 접근이 허용된 다른 폴더의 범위가 겹치는 경우 동일한 위치에 계속 접근할 수 있습니다.

로컬 데이터
환경설정, 윈도우 레이아웃 및 폴더 권한은 이 Mac에 저장됩니다. 압축 파일 암호는 메모리에 보관되며 도구 메뉴에서 지우거나 앱을 종료하여 지울 수 있습니다. 미리보기 및 중첩 압축 파일 작업은 복호화된 내용을 포함하는 비공개 임시 복사본을 생성할 수 있으며, 이는 정상적인 정리 과정에서 제거됩니다. 프로세스가 중단되면 시스템 또는 이후 정리 과정에서 제거될 때까지 임시 파일이 남을 수 있습니다. 설정 > 일반에서 임시 폴더를 Finder에 표시하거나 사용하지 않는 임시 파일을 정리할 수 있습니다. 사용 중인 파일은 유지됩니다. 선택적으로 보관하는 복구용 복사본도 이 임시 폴더에 저장되며, 임시 파일 정리 기능이나 macOS에 의해 삭제될 수 있습니다.

외부 작업
Finder에서 보기는 선택한 파일을 macOS Finder에 표시합니다. 미리보기는 VibeZip 안에서 수행됩니다. GitHub 버튼은 웹 브라우저에서 프로젝트 페이지를 엽니다. VibeZip은 압축 파일의 내용을 실행하거나 외부 뷰어 또는 편집기에서 파일을 열지 않습니다.
